## 1.2.0 发布验收记录

日期：2026-10-29。本记录说明 1.2.0 的发布验证范围；发行包见 [GitHub Release](https://github.com/huang-kai/primebuddy/releases/tag/v1.2.0)。

### 本版范围

- Buddy 1.2.0，点歌台 0.4.1，成语接龙 0.2.0。
- 继续使用原厂媒体播放，不接入 TCP 播放试验代码。
- 音乐播放期间不响应唤醒词业务指令，等待播放结束后输入下一句；唤醒打断留待后续版本。
- 游戏退出后 Buddy 接管已有用户现场验收，保留该结论，不重新列为从未验证。
- 技能发现、能力目录、列表和安装向导按技能隔离损坏记录；保留配置、数据和原启用选择。遗留进程与资源释放核验不被隔离逻辑绕过。

没有修改用户的永久 `commissioned`、`verified` 或动作启用配置。本版不宣称所有型号和形态已完成动作验收。
